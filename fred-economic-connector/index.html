Looker Studio Community Connector

FRED Economic Data

Zero-server, BYOK Google Looker Studio Community Connector streaming 800,000+ Federal Reserve Economic Data (FRED) macroeconomic series directly from the St. Louis Fed REST API.

Connect in Looker Studio View Template Report

Private BYOK Authentication

Uses AuthTypes.KEY so every user supplies their own free 32-character FRED API key, stored strictly per-user inside Google's PropertiesService.getUserProperties().

Native FRED Transformations

Supports flagship presets (CPIAUCSL, GDP, FEDFUNDS, UNRATE, DGS10, M2SL) or any custom Series ID with server-side YoY % (pc1), MoM % (pch), and frequency resampling.

Zero-Server & Secret Hygiene

Runs 100% inside Google Apps Script V8 with strict script.external_request scope, urlFetchWhitelist pinned to api.stlouisfed.org, and SHA-256 secret-free caching.

Semantic Schema Reference

The connector exposes 8 deterministic fields (5 dimensions and 3 metrics) for macroeconomic time-series analysis, KPI scorecards, and multi-series dashboard blending:

Field Name Field ID Type Description
Date date Date (YYYYMMDD) Observation date formatted for continuous Looker Studio time-series charts.
Year year Year (YYYY) 4-digit observation year for annual rollups and period comparisons.
Series ID series_id Text Resolved uppercase FRED Series ID (e.g., CPIAUCSL, FEDFUNDS).
Series Label series_label Text Custom display label if configured, otherwise defaults to the resolved Series ID.
Units Code units_code Text Applied FRED transformation code (lin, chg, pch, pc1, log).
Value value Number (AVG) Parsed numeric observation value (Average aggregation prevents distortion across time buckets).
Value (Sum) value_sum Number (SUM) Additive sum metric suitable for volume or flow series.
Observation Count observation_count Number (SUM) Count of valid non-missing observations (FRED "." sentinels are filtered cleanly).

Quick Start & Support

  • Step 1: Obtain a free 32-character API key from your St. Louis Fed FRED Account.
  • Step 2: Click Connect in Looker Studio above, authorize script.external_request, and paste your personal FRED API key when prompted.
  • Step 3: Pick a macroeconomic preset (or choose CUSTOM and enter any FRED Series ID), select your unit transformation (such as pc1 for YoY %) and optional frequency aggregation, and click Connect.
  • Support Contact: For bug reports, feature requests, or integration assistance, reach out via danielchakraborty.com.
