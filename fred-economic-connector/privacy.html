Privacy Policy

FRED Economic Data — Google Looker Studio Community Connector • Effective Date: November 18, 2026

1. Overview & Zero-Server Architecture

FRED Economic Data is an open-source Google Looker Studio Community Connector developed and maintained by Daniel Chakraborty (danielchakraborty.com). The connector executes strictly within Google Apps Script's managed V8 runtime and communicates directly with the Federal Reserve Bank of St. Louis FRED REST API (api.stlouisfed.org).

2. BYOK Credential Isolation

The connector uses a Bring-Your-Own-Key (AuthTypes.KEY) model:

  • Per-User Storage Only: Your 32-character FRED API key is stored exclusively inside Google Apps Script's isolated PropertiesService.getUserProperties() container bound to your Google account.
  • Zero Developer Visibility: The developer cannot read, access, log, or retrieve any user's FRED API key. Error messages and cache keys are sanitized so API keys are never written to logs or shared caches.
  • Revocation at Any Time: You can clear your stored API key immediately inside Looker Studio via Revoke Access on the data source.

3. Information We Do Not Collect

  • No Personal Identifiable Information (PII): The connector does not collect, read, store, or transmit your name, email address, Google profile, or IP address to any developer-controlled server.
  • No External Proxy Servers or Databases: We operate zero backend servers, analytics trackers, cookies, or third-party logging endpoints.
  • No Report Data Persistence: Selected FRED series IDs, transformation units, frequency settings, and date ranges remain inside your Looker Studio report configuration.

4. OAuth Scope & Network Lockdown

The connector requests only the minimum OAuth scope required to fetch macroeconomic series, further restricted via manifest urlFetchWhitelist rules:

  • https://www.googleapis.com/auth/script.external_request — Used exclusively to issue outbound HTTPS GET requests to https://api.stlouisfed.org/.

5. Transient Caching

To improve dashboard responsiveness and respect upstream API rate limits, public FRED observation responses may be temporarily cached for up to 30 minutes inside Google Apps Script's ephemeral CacheService. Cache keys are derived via SHA-256 hash of non-secret query parameters (series_id, date range, units, and frequency) and never contain API keys or user-identifying metadata.

6. Google API Services User Data Policy

Use and transfer of information received from Google APIs adheres strictly to the Google API Services User Data Policy, including the Limited Use requirements.
