Two-Sheet Diff, Record Reconciliation & Visual Auditing

Compare monthly billing, vendor rosters, inventory counts, or system exports directly inside Google Sheets. Replaces brittle VLOOKUP/MATCH chains with an in-memory hash comparison that flags added, removed, and modified values in seconds.

Engineered for Deterministic Accuracy

A zero-cost, client-side utility built strictly to solve period-over-period reconciliation without cloud dependencies or complex formulas.

⚙

Composite Key Indexing

Match entities across sheets using single identifiers (Account_ID, SKU) or multi-column composite keys (First_Name + Last_Name) with high-speed in-memory Map lookup.

✓

Cell-Level Delta & Variance

Identifies exact modified fields between matching keys, capturing old vs. new values alongside calculated absolute variance and percentage delta for numeric columns.

👁

Non-Destructive Visual Overlay

Optionally highlight additions in soft green and modified values in soft yellow directly on the comparison sheet, populated with cell notes containing previous values.

📝

Structured Audit Report Tab

Compiles a dedicated Diff_Reconciliation_Report tab containing an executive scorecard (Added, Removed, Modified, Unchanged) and a granular delta table.

✂

Data Normalization Rules

Built-in toggles to ignore leading/trailing whitespace, bypass case sensitivity, and evaluate empty cells vs. 'N/A' or '#N/A' sentinels as equivalent.

🗄

One-Click Highlight Reset

Native menu action to clear all color overlays and cell notes in bulk without mutating values, row positions, or underlying formula references.

Zero External Network Footprint & Strict Scopes

SheetDiff & Reconciliation Studio runs 100% within your spreadsheet via the Google Apps Script V8 runtime. Your rows and cells are never sent to an external server, third-party database, or language model. The add-on operates strictly with the least-privilege, container-safe OAuth scope:

✔ https://www.googleapis.com/auth/spreadsheets.currentonly

Restricts add-on read and write execution exclusively to the specific spreadsheet file you have opened. It cannot access your other Google Drive files or personal account data.
