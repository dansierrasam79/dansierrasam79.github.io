oauth-scope-minimizer

A deterministic pre-tool gatekeeper that intercepts overly broad Google Apps Script OAuth scopes (W1–W7) and Chrome Manifest V3 permissions or CSP directives (C1–C10) before files touch disk—preventing Google Workspace Marketplace and Chrome Web Store review rejections at authoring time.

View on GitHub (dansierrasam79/oauth-scope-minimizer) Release v1.0.0

One-Click Installation

Dual-packaged for native remote installation across both Google Antigravity and Gemini CLI with zero external dependencies.

Google Antigravity CLI (PreToolUse hook + skill + rules) Antigravity v1.5+

Gemini CLI Extension (BeforeTool hook + AGENTS.md) Gemini CLI

Deterministic Architecture

Zero-Dependency Stdlib

scripts/scope_gate.py uses strictly Python 3 standard library modules (json, sys, os, re, pathlib)—no pip packages, no network calls, zero telemetry.

Clean Stdout / Stderr Contract

Emits pure JSON decision payloads to stdout and routes all diagnostics strictly to stderr so agent JSON parsers never break.

Fail-Open Safety

Non-target files, malformed JSON drafts, or unexpected stdin shapes cleanly emit {} with exit code 0 so normal development is never stalled.

Non-Overridable MV3 Locks

Project-level .scope-allowlist.json overrides work for justified scopes, while critical Manifest V3 CSP rules (C8 & C9) remain permanently locked.

Google Workspace & Apps Script Rules (W1–W7)

Evaluated on every write or edit targeting appsscript.json. Broad scopes are blocked before disk write and paired with narrow .currentonly or Picker alternatives.

Rule Action Blocked Broad Scope Least-Privilege Alternative
W1 DENY .../auth/spreadsheets
.../auth/spreadsheets.readonly		 .../auth/spreadsheets.currentonly
W2 DENY .../auth/documents
.../auth/documents.readonly		 .../auth/documents.currentonly
W3 DENY .../auth/presentations
.../auth/presentations.readonly		 .../auth/presentations.currentonly
W4 DENY .../auth/forms
.../auth/forms.readonly		 .../auth/forms.currentonly
W5 DENY .../auth/drive .../auth/drive.file (Google Picker / app-created files)
W6 DENY .../auth/drive.readonly .../auth/drive.file or .../auth/drive.metadata.readonly
W7 DENY https://mail.google.com/
.../auth/gmail.modify		 .../auth/gmail.addons.current.message.readonly / .action

Chrome Extension Manifest V3 Rules (C1–C10)

Evaluated on every write or edit targeting Manifest V3 manifest.json files (Manifest V2 files are ignored).

Rule Action Detected Pattern Least-Privilege Remediation
C1 DENY <all_urls> in host_permissions or content_scripts Use activeTab + scripting or explicit target origins
C2 DENY *://*/* or https://*/* wildcard host access Restrict to specific domains or invoke on click via activeTab
C3 DENY http://*/* cleartext wildcard host access Use HTTPS-only specific origins
C4 DENY tabs in permissions Replace with activeTab unless reading URLs/titles across background tabs
C5 DENY webRequest or webRequestBlocking Migrate to declarativeNetRequest
C6 DENY debugger in permissions Use standard WebExtensions APIs (scripting, tabs, storage)
C7 DENY cookies in permissions Use storage.local or identity OAuth flows
C8 NON-OVERRIDABLE Remote URLs (https://, http://) in content_security_policy.extension_pages Bundle all scripts locally inside the extension package (MV3 requirement)
C9 NON-OVERRIDABLE 'unsafe-eval' in content_security_policy.extension_pages Remove dynamic code evaluation; use CSP-safe builds (MV3 requirement)
C10 ALLOW + WARN 'unsafe-eval' in content_security_policy.sandbox Permitted in sandboxed pages; verify sandbox isolation boundary

Project-Level Allowlist Override

When an extension or add-on genuinely requires a broader scope (with documented OAuth verification justification), add a .scope-allowlist.json file at your project root. Rules C8 and C9 cannot be overridden. 

{
  "appsscript.json": {
    "allowedScopes": [
      "https://www.googleapis.com/auth/spreadsheets"
    ],
    "justification": "Batch cross-spreadsheet audit tool verified under restricted scope review."
  },
  "manifest.json": {
    "allowedPermissions": ["tabs"],
    "allowedHostPatterns": [],
    "justification": "Tab manager extension grouping open tabs across windows."
  }
}
