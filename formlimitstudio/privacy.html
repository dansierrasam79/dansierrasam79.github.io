Privacy Policy for FormLimit Studio

Last updated: November 7, 2026

This Privacy Policy describes how FormLimit Studio ("we", "us", or "our") accesses, processes, and protects your data when you install and use our Google Workspace™ add-on.

1. Architecture and Zero External Data Storage

FormLimit Studio operates on a zero-server, zero-external-storage architecture. The add-on is executed entirely within your Google account using Google Apps Script™ infrastructure:

  • We run no external servers, databases, analytics loggers, or API tracking endpoints.
  • We never transmit, sell, log, or broker your Google Forms™ data, user emails, or respondent submissions to any third party.
  • All configuration limits (such as response threshold counts, target deadlines, custom closure messages, and notification preferences) are stored strictly inside your form's native PropertiesService within your Google account.

2. Data Protection Mechanisms for Sensitive Data

We take data protection and the security of sensitive user data seriously. FormLimit Studio protects sensitive and restricted data through the following mechanisms:

  • Encryption in Transit: All communications between the client interface, Google Forms™, and Google Apps Script™ APIs are encrypted in transit using industry-standard Transport Layer Security (TLS 1.2/1.3 / HTTPS). Data is never routed over unencrypted HTTP channels.
  • Encryption at Rest: FormLimit Studio maintains zero external databases. All persistent configurations and sensitive OAuth access tokens are secured at rest within Google Cloud infrastructure using standard Google Workspace encryption mechanisms (AES-256 bit encryption at rest).
  • In-Memory Processing & Session Isolation: Execution of respondent count checks, trigger scheduling, and email alert logic occurs strictly in-memory during active Apps Script runtime execution sessions. No sensitive data, submission contents, or email payloads are cached, logged, or serialized externally.
  • Strict Scope Minimization & Access Controls: Access is guarded via Google's OAuth 2.0 authorization framework. The add-on requests only container-bound and least-privilege scopes (e.g., forms.currentonly). Processing is strictly restricted to the executing user's session (Session.getEffectiveUser()), preventing any cross-user or external system access.

3. Google OAuth Permissions & Data Use Disclosures

In accordance with the principle of least privilege, FormLimit Studio requests only the minimal permissions required to function:

OAuth Scope Purpose and Exact Usage
https://www.googleapis.com/auth/forms.currentonly Allows the add-on to view and manage only the specific Google Form where you open the add-on. Used solely to toggle acceptance status, set the custom closed message, and check the submission count.
https://www.googleapis.com/auth/script.container.ui Allows the add-on to display the interactive sidebar interface inside the Google Forms editor.
https://www.googleapis.com/auth/script.scriptapp Allows the add-on to install, execute, and delete local triggers (form submit triggers and time-based clock triggers) that automate form closing.
https://www.googleapis.com/auth/userinfo.email Identifies the email address of the form owner executing the add-on via Session.getEffectiveUser().getEmail() to establish the destination for closure alerts.
https://www.googleapis.com/auth/script.send_mail Permits the add-on to send a transactional notification email via MailApp.sendEmail() exclusively to the form owner when a configured submission cap or deadline is reached.
Limited Use Policy Compliance:
FormLimit Studio's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. AI and Machine Learning Model Training

FormLimit Studio does not use, transfer, or disclose Google Workspace user data or respondent data to train, retrain, or improve generalized or non-personalized machine learning (ML) or artificial intelligence (AI) models.

5. Human Access to Data

We do not allow human access to your Google Forms content or submission responses. Because all processing executes in your own Google account via Google Apps Script runtime, no personnel or contractors have access to your forms or form entries.

6. Data Retention and Deletion

  • No External Retention: Because we do not store your data on external databases, there is no external profile or stored data footprint to manage or delete.
  • Form Data Removal: All stored configuration parameters reside within the Google Form container. Deleting the Google Form or clearing the limits from the sidebar purges the configuration.
  • Revoking Access: You can completely revoke FormLimit Studio's permissions at any time via your Google Account Permissions Dashboard or by uninstalling the add-on from Google Workspace Marketplace™.
