📐 Method 2: In-Cell Formulas

Native custom functions that calculate dynamically across spreadsheet cells with zero external API calls.

Formula Description
=HEBREW_DATE(date) Converts Gregorian date into full Hebrew representation with Gematria.
=IS_CHAG(date, [type]) Detects Jewish holidays, fast days, and Israeli statutory events.
=ISRAEL_WORKDAYS(start, end, ...) Computes net business days enforcing the Sunday–Thursday workweek.
=ISRAEL_WORKDAY_ADD(start, n, ...) Adds N business days advancing across weekends and statutory Chagim.

Privacy-First Architecture

Luach Harmonizer operates under strict minimal OAuth scopes:

  • https://www.googleapis.com/auth/spreadsheets.currentonly — Accesses only the active spreadsheet running the add-on.
  • https://www.googleapis.com/auth/script.container.ui — Renders the sidebar interface and dialog prompts.

Zero Telemetry: All calendar calculations and schedule harmonizations execute strictly in-memory inside your browser and Google Apps Script runtime. No user data, spreadsheet values, or analytics are ever collected, logged, or transmitted to any external server.
