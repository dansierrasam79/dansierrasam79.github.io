Privacy Policy for Sheet Consolidator Studio

Effective Date: November 1, 2026 | Last Updated: November 1, 2026

1. Overview and Core Privacy Principle

Sheet Consolidator Studio ("the Add-on", "we", "our") is an Editor Add-on built for Google Sheets™. The Add-on executes 100% deterministic multi-tab appending, schema reconciliation (union and intersection), repeated header elimination, whitespace trimming, and source provenance tracking locally inside your Google Apps Script V8 runtime session. We do not collect, store, transmit, monetize, share, transfer, or disclose your spreadsheet data, personal information, or user files.

2. Permissions and OAuth Scopes Used

The Add-on requests strictly minimal OAuth scopes required solely to perform data consolidation operations within the active document:

  • https://www.googleapis.com/auth/spreadsheets.currentonly: Allows the Add-on to read source tab data and write consolidated output tables only in the specific, active spreadsheet where you launch it. It cannot view, access, or alter any other files across your Google Drive.
  • https://www.googleapis.com/auth/script.container.ui: Allows the Add-on to render its custom HTML/CSS sidebar interface and native dialog prompts inside Google Sheets via SpreadsheetApp.getUi(). It is not used to embed third-party tracking scripts or external web frames.

3. Data Processing Architecture

  • In-Memory Processing: All transformations (extracting tab values, aligning column schemas, eliminating repeated headers, trimming whitespace, and unioning rows) execute entirely in-memory within your active browser session and Google Apps Script sandbox.
  • Zero External Transmission: The Add-on contains zero external webhooks, telemetries, third-party analytics trackers, or external database calls. Your cell values and spreadsheet metadata never leave Google's official infrastructure.
  • No Artificial Intelligence or LLM Processing: The Add-on operates purely on deterministic JavaScript array manipulation and standard regular expressions. No user data is sent to external AI models or used for model training.

4. Data Storage and Retention

Because Sheet Consolidator Studio does not operate external databases, logging systems, or servers, no user data, spreadsheet contents, tokens, or profile information is ever stored, logged, or retained by us.

5. Third-Party Sharing, Transfer, and Disclosure

We do not sell, rent, trade, share, transfer, or disclose Google user data, spreadsheet contents, or personal information to any third parties, advertising platforms, or data brokers. All computational operations remain strictly confined between your authenticated Google account and Google Cloud's official Apps Script infrastructure.

6. Google API Services User Data Policy & Limited Use Compliance

Sheet Consolidator Studio's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. User Rights and Access Revocation

Because the Add-on does not retain user data on external servers, there is no persistent personal data stored to inspect, modify, or delete. Users retain complete control over application access and may revoke the Add-on's permissions at any time through Google Account Permissions at myaccount.google.com/connections.

8. Changes to This Policy

We may update this Privacy Policy from time to time to maintain compliance with platform guidelines. Any revisions will be published directly to this page with an updated "Last Updated" date.
