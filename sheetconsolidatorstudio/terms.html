1. Description of Service

Sheet Consolidator Studio is an Editor Add-on built for Google Sheets™ providing deterministic multi-tab appending, schema reconciliation (union and intersection), repeated header elimination, whitespace trimming, and source provenance tracking. The Add-on executes 100% in-memory within your active Google Apps Script V8 runtime session without external data storage, third-party network transmissions, or telemetry tracking.

3. Non-Destructive Operation & User Responsibility

Sheet Consolidator Studio defaults to outputting consolidated datasets into a dedicated sheet tab (e.g., Consolidated_Master) to prevent accidental overwriting of raw data source tabs. When running consolidations into existing target tabs, the target sheet is refreshed with the new consolidated matrix. Users are advised to review target sheet configurations and utilize Google Sheets Version History (File > Version history) for critical enterprise datasets.
