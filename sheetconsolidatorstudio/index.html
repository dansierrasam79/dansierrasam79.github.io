Google Sheets™ Editor Add-on

Sheet Consolidator Studio

Deterministic, in-memory multi-tab appending, schema reconciliation, and workbook union for Google Sheets™.

Overview

Sheet Consolidator Studio is a lightweight productivity add-on engineered to merge, append, and stack rows across multiple tabs within an active spreadsheet into a unified master view. Built for predictable, audit-ready data wrangling, it harmonizes disparate column layouts, strips redundant headers, and tracks row provenance without sending data outside your document.

Header-Based Matching

Aligns fields dynamically across tabs regardless of column order, supporting both Union (all unique headers) and Intersection (common headers only) schemes.

Positional Stacking

Appends tables strictly by their physical column positions (Column A → Column A) for identically structured exports lacking unified headers.

Interactive Tab Filtering

Target dozens of sheets quickly using regex pattern filtering (such as ^202[0-9]_.* or Month_*) with live multi-selection.

Automated Ingestion Hygiene

Automatically trims extraneous cell whitespace, drops blank rows, skips embedded duplicate header rows, and performs Union Distinct deduplication.

Row Provenance Tracking

Optionally injects Source_Sheet_Name and Source_Row_Index columns into the output dataset for complete source traceability.

Memory-Safe Execution

Executes entirely in-memory using chunked batch writes, guarded by pre-computation limits to prevent spreadsheet performance degradation.

Technical & Security Architecture

Sheet Consolidator Studio operates under a strict least-privilege security model designed to meet Google Cloud Trust & Safety standards:

OAuth Scope Usage Rationale
.../auth/spreadsheets.currentonly Permits read access across user-selected tabs and write operations into the target consolidated sheet solely within the active document. Cannot access any other Drive files.
.../auth/script.container.ui Renders the native sidebar, custom tab picker, and progress dialogs directly inside the Google Sheets interface via HTML Service.
  • Zero External Transmission: Contains no external webhooks, analytics trackers, or network calls.
  • No Server Persistence: No databases, third-party cloud servers, or session caching mechanisms.
  • Deterministic Processing: Pure deterministic array operations without third-party AI/LLM model routing or training.
