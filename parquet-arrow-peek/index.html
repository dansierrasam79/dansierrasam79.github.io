Dual-Layer Zero-Egress Architecture

Separates metadata discovery from code execution so agents write deterministic Polars, DuckDB, or SQL pipelines without ever reading raw records.

LAYER 1 • GUARDRAIL HOOK

PreToolUse / BeforeTool Blocker

Intercepts view_file and read_file calls targeting columnar binaries or large tabular files (> 50 KB) in < 15 ms using 100% Python stdlib, redirecting the agent to inspect_schema.

LAYER 2 • STDIO MCP SERVER

O(1) Footer & Head Inspector

Reads Parquet/Arrow footers via pyarrow without decoding data pages, and samples only the first 64 KB of CSV/JSONL files. Redacts string/binary min/max stats into byte lengths.

LAYER 3 • AI SKILL

Schema-First Code Generation

skills/parquet-arrow-peek/SKILL.md instructs the agent to generate local DuckDB/Polars scripts that write outputs to disk or print scalar aggregates only—never df.head().

Guardrail Interception Policy

Deterministic rules enforced before any file bytes enter the model context window.

File Extension Size Threshold Decision Agent Action
.parquet, .arrow, .feather, .ipc Any size (≥ 0 B) DENY Blocked unconditionally; redirected to inspect_schema MCP tool
.csv, .tsv, .jsonl, .ndjson > 50 KB (51,200 B) DENY Blocked to prevent context blowout; redirected to inspect_schema
.csv, .tsv, .jsonl, .ndjson ≤ 50 KB (51,200 B) ALLOW Permitted for small lookup tables and configuration files
All other extensions Any size ALLOW Pass-through with zero interference
