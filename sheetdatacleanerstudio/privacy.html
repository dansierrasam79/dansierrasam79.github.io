Privacy Policy for Sheet Data Cleaner Studio

Effective Date: October 24, 2026 | Last Updated: October 25, 2026

1. Overview and Core Privacy Principle

Sheet Data Cleaner Studio ("the Add-on", "we", "our") is an Editor Add-on built for Google Sheets™. The Add-on is engineered on a strict zero-data-collection, client-side execution model. It executes 100% deterministic data transformation and sanitization algorithms locally inside your Google Apps Script V8 runtime session. We do not collect, store, transmit, monetize, share, transfer, or disclose your spreadsheet data, personal information, or user files.

2. Permissions and OAuth Scopes Used

The Add-on requests strictly narrow, essential OAuth scopes required solely to perform spreadsheet operations within the active document:

  • https://www.googleapis.com/auth/spreadsheets.currentonly: Allows the Add-on to read and format data only in the specific, active spreadsheet where you launch it. It cannot view, access, or alter any other spreadsheets or files across your Google Drive.
  • https://www.googleapis.com/auth/script.container.ui: Allows the Add-on to display its custom HTML/CSS sidebar interface and native dialog prompts inside Google Sheets via SpreadsheetApp.getUi(). It is not used to embed or load third-party scripts or external web frames.

3. Data Processing Architecture

  • In-Memory Processing: All data transformations (whitespace sanitization, duplicate identification, date standardization, casing changes, missing value handling, and schema exports) run entirely in-memory within your active browser session and Google Apps Script's execution sandbox.
  • Zero External Transmission: The Add-on contains zero external webhooks, telemetries, third-party analytics trackers, or external database calls. Your cell values and spreadsheet metadata never leave Google's official infrastructure.
  • No Artificial Intelligence or LLM Processing: The Add-on operates on pure deterministic regular expressions and standard JavaScript array algorithms. No user data is sent to external artificial intelligence models or used for model training.

4. Data Storage and Retention

Because Sheet Data Cleaner Studio does not operate external databases, logging systems, or servers, no user data, spreadsheet contents, tokens, or profile information is ever stored, logged, or retained by us.

5. Third-Party Sharing, Transfer, and Disclosure

We do not sell, rent, trade, share, transfer, or disclose Google user data, spreadsheet contents, or personal information to any third parties, advertising platforms, or data brokers. All computational operations remain strictly confined between your authenticated Google account and Google Cloud's official Apps Script infrastructure.

6. Google API Services User Data Policy & Limited Use Compliance

Sheet Data Cleaner Studio's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. User Rights and Access Revocation

Because the Add-on does not retain user data on external servers, there is no persistent personal data stored to inspect, modify, or delete. Users retain complete control over application access and may revoke the Add-on's permissions at any time through Google Account Permissions at myaccount.google.com/connections.

8. Changes to This Policy

We may update this Privacy Policy from time to time to maintain compliance with applicable platform guidelines. Any revisions will be published directly to this page with an updated "Last Updated" date.
