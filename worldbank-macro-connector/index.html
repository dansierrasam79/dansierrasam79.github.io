Looker Studio Community Connector

World Bank Macro Indicators

Zero-server, keyless Google Looker Studio Community Connector streaming live macroeconomic time series directly from the World Bank Open Data API v2.

Connect in Looker Studio View Template Report

Keyless Public Access

Uses AuthTypes.NONE with zero API key setup. Every Looker Studio viewer queries World Bank Open Data directly under their own session.

Zero-Server Architecture

Runs 100% inside Google Apps Script V8 with strict script.external_request scope and 30-minute in-memory caching. No proxy servers or external databases.

Multi-Country & Custom WDI

Filter by semicolon-separated ISO-3 codes or query all economies, exclude regional aggregates, and pull any World Development Indicators (WDI) code.

Semantic Schema Reference

The connector exposes 9 deterministic fields (6 dimensions and 3 metrics) for geographic maps, time-series charts, and executive scorecards:

Field Name Field ID Type Description
Country / Economy Name country_name Country (Text) Official World Bank economy or regional aggregate name.
Country ISO-3 Code country_iso3 Country (ISO-3) 3-letter ISO 3166-1 alpha-3 code for filled Geo Charts.
Indicator ID indicator_id Text World Bank WDI series identifier (e.g., NY.GDP.MKTP.CD).
Indicator Name indicator_name Text Full descriptive title of the selected World Bank indicator.
Observation Date observation_date Date (YYYYMMDD) January 1st of the observation year for continuous timelines.
Year year Year (YYYY) 4-digit observation year for annual comparisons.
Indicator Value value Number (AVG) Reported numeric value (Average default aggregation).
Indicator Value (Sum) value_sum Number (SUM) Additive sum metric suitable for volume indicators like GDP or Population.
Observation Count observation_count Number (SUM) Count of valid non-null observations returned.

Quick Start & Support

  • Step 1: Click Connect in Looker Studio above and authorize the minimal external network permission (script.external_request).
  • Step 2: Choose a built-in macroeconomic preset (such as GDP Current US$, GDP Growth %, Inflation CPI %, or Population) or enter a custom World Bank WDI series ID.
  • Step 3: Specify semicolon-separated ISO-3 country codes (e.g., USA;IND;DEU;JPN;GBR) or enter all to retrieve all economies.
  • Support Contact: For bug reports, feature requests, or integration assistance, reach out via danielchakraborty.com.
