Privacy Policy

Open-Meteo Weather Data — Google Looker Studio Community Connector • Effective Date: November 18, 2026

1. Overview & Zero-Server Architecture

Open-Meteo Weather Data is an open-source Google Looker Studio Community Connector developed and maintained by Daniel Chakraborty (danielchakraborty.com). The connector executes strictly within Google Apps Script's managed V8 runtime and communicates directly with Open-Meteo's public REST endpoints (api.open-meteo.com and archive-api.open-meteo.com).

2. Information We Do Not Collect

We operate on a strict zero-collection, zero-telemetry architecture:

  • No Personal Identifiable Information (PII): The connector does not collect, read, store, or transmit your name, email address, Google profile, or IP address to any developer-controlled server.
  • No External Proxy Servers or Databases: We operate zero backend servers, analytics trackers, cookies, or third-party logging endpoints.
  • No Report Data Persistence: Configuration parameters (latitude, longitude, location labels, unit selections, and date ranges) remain inside your Looker Studio report configuration and are never exported outside Google's infrastructure.

3. OAuth Scope & Network Lockdown

The connector requests only the minimum OAuth scope required to fetch public meteorological datasets, further restricted via manifest urlFetchWhitelist rules:

  • https://www.googleapis.com/auth/script.external_request — Used exclusively to issue outbound HTTPS GET requests to https://api.open-meteo.com/ and https://archive-api.open-meteo.com/.

4. Transient Caching

To improve dashboard responsiveness and respect upstream API rate limits, public Open-Meteo JSON responses may be temporarily cached inside Google Apps Script's ephemeral CacheService. Cached entries are keyed by a SHA-256 hash of the public request URL and contain zero user-identifying metadata.

5. Google API Services User Data Policy

Use and transfer of information received from Google APIs adheres strictly to the Google API Services User Data Policy, including the Limited Use requirements.

6. Contact

If you have questions regarding this Privacy Policy or the connector's security posture, please contact Daniel Chakraborty via danielchakraborty.com.
