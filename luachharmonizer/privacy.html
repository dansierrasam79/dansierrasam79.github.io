Privacy Policy

Application: Luach Workweek & Jewish Calendar Harmonizer • Effective Date: November 7, 2026 • Last Updated: November 9, 2026 • Developer: Daniel Chakraborty

Zero-Telemetry Commitment: Luach Harmonizer is built on a strict privacy-first, client-side architecture. All Hebrew date conversions, statutory holiday detections, and schedule adjustments execute 100% locally in-memory within your active browser session and Google Apps Script runtime. No user data is ever collected, stored, tracked, or transmitted to external servers.

1. Overview and Core Privacy Principle

This Privacy Policy describes how Luach Workweek & Jewish Calendar Harmonizer ("Luach Harmonizer", "the Add-on", "we", "our", "us") handles data when you install and use the Add-on within Google Sheets™. The Add-on executes 100% deterministic lunisolar conversion and timeline adjustment algorithms locally inside your Google Apps Script™ runtime session. We do not collect, store, transmit, monetize, share, transfer, or disclose your spreadsheet data, personal information, or user files.

2. Google User Data Accessed by the Application

In accordance with Google API Services User Data Policy disclosures, Luach Harmonizer accesses only the minimal user data essential to execute calendar conversions and timeline adjustments within the active workbook:

  • Designated Spreadsheet Cell Values: When you execute a timeline adjustment or invoke a custom formula (such as =HEBREW_DATE(), =IS_CHAG(), =ISRAEL_WORKDAYS(), or =ISRAEL_WORKDAY_ADD()), the Add-on reads input date, task duration, and milestone values exclusively from the cells you explicitly pass as arguments or select in the active sheet.
  • Calculated Cell Outputs: The Add-on writes computed Hebrew calendar representations and adjusted completion dates directly back to the active spreadsheet.
  • Active Spreadsheet Timezone: The Add-on queries the document's local timezone (via native Apps Script methods) strictly to avoid calendar date shift anomalies during conversions.
  • Local Container Interface Events: The Add-on receives user interaction events (button clicks, column mappings, and Chagim toggles) within the sidebar to adjust calculation parameters.
  • Strict Document-Level Isolation: The Add-on cannot view, search, read, access, or modify any other files, folders, or documents stored in your Google Drive™. It does not access your Google Account email address, personal profile, or contact lists.

3. Minimal Google OAuth Scopes

Luach Harmonizer requests only minimal OAuth scopes required for core functionality:

  • https://www.googleapis.com/auth/spreadsheets.currentonly — Grants access exclusively to the specific Google Sheets document where you explicitly launch or execute the Add-on. It cannot access, read, or modify any other spreadsheets or files across your Google Drive.
  • https://www.googleapis.com/auth/script.container.ui — Allows the Add-on to display user interfaces inside Google Sheets, including the task harmonizer sidebar, demo sheet generation alerts, and configuration dialogs via SpreadsheetApp.getUi(). It is not used to embed external tracking scripts, third-party web content, or advertising frames.

4. Data Protection and Security Mechanisms for Sensitive Data

We implement comprehensive technical and operational safeguards to secure Google user data and protect sensitive spreadsheet information:

  • Encryption in Transit: All communications between the Google Sheets client interface and the Google Apps Script execution runtime are strictly encrypted in transit using industry-standard Transport Layer Security (HTTPS / TLS 1.2 or higher) provided directly by Google infrastructure.
  • Runtime Sandbox Isolation: The Add-on executes strictly within Google Apps Script's secure V8 container sandbox, preventing unauthorized script injection, cross-site scripting (XSS), or memory leakage outside the immediate document container.
  • Ephemeral In-Memory Handling: Cell data retrieved from the active range resides temporarily in volatile script memory solely for the duration of the deterministic calendar conversion algorithm. Memory is purged immediately upon function completion, ensuring zero persistent caching, residue, or disk storage.
  • Zero Third-Party Code or Network Egress: The Add-on contains zero external network dependencies (no UrlFetchApp calls), zero third-party analytics trackers, zero advertising SDKs, and zero external database endpoints. All computational operations remain strictly confined within Google's official cloud runtime.

5. Data Retention and Deletion of Google User Data

  • Zero Data Retention: Luach Harmonizer maintains a strict zero-retention policy. We do not operate external servers, databases, or logging backends. No Google user data, cell values, formulas, metadata, or authentication tokens are ever stored, logged, cached, or retained on any external system. All data exists ephemerally in runtime memory and ceases to exist as soon as the execution finishes or the browser tab closes.
  • Data Deletion: Because no user data is ever collected or retained on our systems, there is no stored data to delete.
  • User Access Revocation: Users have complete control over application permissions at all times. You can immediately revoke Luach Harmonizer's access by visiting Google Account Permissions (Third-party apps with account access), selecting Luach Harmonizer, and clicking Delete all connections / Remove Access. Alternatively, you can uninstall the Add-on directly within Google Sheets via Extensions > Add-ons > Manage add-ons.

6. Third-Party Sharing, Transfer, and Disclosure

We do not sell, rent, trade, share, transfer, or disclose Google user data, spreadsheet contents, or personal information to any third parties, advertising platforms, data brokers, or marketing intermediaries. All operations are strictly confined between your authenticated Google account and Google Cloud's official Apps Script infrastructure.

7. AI and Machine Learning Model Training Restrictions

Luach Harmonizer does not use, transfer, or disclose Google user data or spreadsheet content to train, retrain, or fine-tune generalized artificial intelligence (AI) or machine learning (ML) models. All calculations are 100% algorithmic and deterministic.

8. Google API Services User Data Policy & Limited Use Compliance

Luach Harmonizer's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements:

  • User data is used exclusively to provide and improve user-facing features of the Add-on within the active spreadsheet.
  • User data is never transferred or sold to third parties, advertising platforms, data brokers, or information resellers.
  • User data is never used for serving advertisements, personalized marketing, or training machine learning models.
  • Human review of user data is strictly prohibited; no human reads or inspects your spreadsheet contents.
