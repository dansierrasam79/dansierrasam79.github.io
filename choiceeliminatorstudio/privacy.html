Privacy Policy for ChoiceEliminator Studio

Effective Date: November 8, 2026 | Last Updated: November 13, 2026
Core Privacy Commitment: ChoiceEliminator Studio operates on a strict zero-server, zero-egress architecture. Your Google Forms™ structure, respondent selections, and quota configurations never leave your Google Account. We operate zero external databases, run no background servers, collect no telemetry, and transmit no data across the network.

1. Overview and Architecture

ChoiceEliminator Studio ("the Add-on", "we", "our") is an Editor Add-on built for Google Forms™. All choice capacity monitoring, dynamic option mutation, and DocumentProperties snapshot restorations execute 100% locally and deterministically inside your Google Apps Script™ V8 runtime session. We do not collect, store, monetize, share, transfer, or disclose your form data, respondent choices, or personal information.

2. Google User Data Accessed by the Application

In accordance with Google API Services User Data Policy disclosures, ChoiceEliminator Studio accesses only the minimal user data required to execute choice-limiting routines within the active form container:

  • Form Item Schema & Choice Strings: Reads question titles and available choices across Multiple Choice, Dropdown, and Checkbox questions strictly to populate the configuration sidebar and update option arrays when capacity limits are reached.
  • Form Response Selections: Evaluates submitted responses locally via installable onFormSubmit events to increment internal tally counters and enforce configured quotas.
  • Configuration Snapshots: Reads and writes question backup states using container-bound PropertiesService.getDocumentProperties() to enable one-click choice restoration.
  • Session Identity & OAuth Tokens: Google account OAuth 2.0 session tokens provided by the Google Workspace runtime are used strictly to establish container execution boundaries and verify active form ownership. We do not inspect, log, or harvest profile details or email addresses.

3. Permissions and OAuth Scopes Used

The Add-on requests strictly least-privilege permissions:

  • https://www.googleapis.com/auth/forms.currentonly: Grants per-file access strictly limited to the specific, active Google Form where the user runs the Add-on. Used to read question items, modify active choice arrays (eliminating exhausted options or prepending "[FULL]"), and process installable form submission triggers.
  • https://www.googleapis.com/auth/script.container.ui: Allows the Add-on to render its configuration sidebar and modal dialogs inside the Google Forms editor via FormApp.getUi(). It is never used to embed external web frames or third-party tracking scripts.

4. Data Protection and Security Mechanisms for Sensitive Data

We implement rigorous technical, cryptographic, and operational security controls to safeguard Google user data and protect sensitive container interactions:

  • Encryption in Transit (HTTPS/TLS 1.2+): All communications between the user's browser, the Google Forms client interface, and Google Apps Script execution services are strictly encrypted in transit using industry-standard Transport Layer Security (HTTPS/TLS 1.2 or TLS 1.3). Data is never transmitted over unencrypted channels.
  • Encrypted Token & Storage Protection (AES-256): ChoiceEliminator Studio never extracts, stores, or caches OAuth 2.0 access tokens or refresh tokens on external servers. All OAuth session tokens and container-bound configuration snapshots (stored in PropertiesService.getDocumentProperties()) reside natively inside Google Cloud infrastructure protected at rest by Google Workspace's AES-256 bit encryption.
  • Restricted Access Controls & Per-File Isolation: Access is governed by OAuth 2.0 least-privilege authorization (forms.currentonly), strictly isolating script execution to the single active form file opened by the authorized user. The Add-on has zero programmatic access to other forms, spreadsheets, or files in the user's Google Drive™.
  • Runtime Sandbox Isolation: All script execution occurs within Google Apps Script's isolated V8 container sandbox, preventing unauthorized script injection, cross-site scripting (XSS), or cross-tenant memory access.
  • Ephemeral In-Memory Processing: Form schema data and submission selections reside temporarily in volatile runtime memory solely for the milliseconds required to evaluate quotas and update choice arrays. Memory is purged immediately upon function termination, leaving zero persistent external cache or data residue.
  • Zero External Egress or Third-Party Dependencies: The Add-on makes zero outbound network calls (UrlFetchApp is absent) and embeds zero third-party client libraries, external CDNs, or analytics trackers.

5. Data Processing Architecture

  • Client-Side Deterministic Logic: All quota evaluations, choice array mutations via setChoiceValues(), and concurrency serializations via LockService run deterministically without external servers.
  • No Artificial Intelligence or LLM Processing: The Add-on operates on deterministic counting logic. No user data is sent to external AI services or used for model training.

6. Data Storage, Retention, and Deletion

Because ChoiceEliminator Studio operates zero external databases, logging systems, or remote servers, we maintain a zero-retention policy outside your Google Form container:

  • Container-Bound Snapshots: Configuration snapshots and tally counters stored in PropertiesService.getDocumentProperties() remain under your exclusive control and are permanently purged when you click "Restore Choices" in the sidebar or delete the Google Form.
  • Permission Revocation: Users may revoke the Add-on's OAuth access at any time via Google Account Permissions or by uninstalling the Add-on from Google Forms.

7. Third-Party Sharing, Transfer, and Disclosure

We do not sell, rent, trade, share, transfer, or disclose Google user data, form contents, respondent submissions, or personal information to any third parties, advertising platforms, or data brokers. All computational operations remain strictly confined between your authenticated Google account and Google Cloud's Apps Script infrastructure.

8. Google API Services User Data Policy & Limited Use Compliance

ChoiceEliminator Studio's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
